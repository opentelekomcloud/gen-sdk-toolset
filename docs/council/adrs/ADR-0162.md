Manual document exclusion is stored in a separate table of the panel DB, outside snapshots: one row for each excluded document of the service, because under ADR-0149 the exclusion applies in all subsequent snapshots, and under ADR-0150 the document is recognized by its path. So a record outside snapshots applies to each new snapshot without being carried over at ingest, and it is set immediately, without a new scan, as ADR-0148 requires; exclusion of a whole service is already stored the same way, in a separate ExcludedService table.
