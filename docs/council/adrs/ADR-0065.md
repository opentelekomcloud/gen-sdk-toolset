A resource name consists of lowercase Latin letters, digits and underscores and starts with a letter (^[a-z][a-z0-9_]*$), because in the Python SDK target from ADR-0055 a resource becomes a separate package services/<service>/<version>/<resource>/, so its name must be a valid snake_case Python package name. The names produced by the preliminary grouping under ADR-0057 already follow this rule.
