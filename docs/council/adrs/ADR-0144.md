The document name in an endpoint row is a link that opens the document file on GitHub in a new tab at the commit of the active snapshot, because on the specification page an operation's document already opens by a link to the file (ADR-0091), so the whole panel will have one way to go to a document. ADR-0146 provides the data for the link, and the new tab keeps the user in the editor along with their unsaved changes.
