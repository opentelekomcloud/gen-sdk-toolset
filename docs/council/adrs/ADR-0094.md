In Entities, a table of fields is shown for each class. The original field name from the API documentation is shown next to the field's SDK name. For each class, it is shown which operations of the resource use it and in what role: request body, query parameters or response, because the user sees in advance in which SDK operations the class will appear and which operations a field type fix under ADR-0108 will affect. The original field name, which under ADR-0097 stays the JSON key, helps find the field in the document even if its SDK name differs.
