If the service already has a grouping, the preliminary grouping cannot be started again: the grouping is changed only by editing it in the editor, because recomputing it with the ADR-0057 rule on the same endpoints would give the same result, and ADR-0071 already puts new endpoints found after a rescan in the "unassigned" list. The ban also keeps manual edits and confirmations and needs no rules for merging the old and new grouping.
