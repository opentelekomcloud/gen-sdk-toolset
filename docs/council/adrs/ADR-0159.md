When a document is excluded, operation edits on its path are deleted; after the exclusion is cancelled, the operation gets the default kind and name. After a rescan, a manual operation edit stays in effect as long as the default kind and name of the operation have not changed; if they have changed, the edit is deleted and the operation gets the new default values, because the rule is simple and leaves no hidden edits in storage that the user does not see. It is consistent with ADR-0158: on exclusion the binding of an endpoint to a resource is deleted, and an operation edit under ADR-0126 is tied to the resource and the document path.

Supersedes: ADR-0117.
