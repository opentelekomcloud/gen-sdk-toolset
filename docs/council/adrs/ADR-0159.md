When a document is excluded, operation edits for its path are deleted; after the exclusion is undone, the operation gets the default kind and name. After a rescan, a manual operation edit stays in effect while the default kind and name of the operation have not changed; if they have changed, the edit is deleted and the operation gets the new default values, because the rule is simple, and no edits the user cannot see are left in storage. Under ADR-0158 an excluded endpoint leaves its resource, and under ADR-0126 an edit is bound to the resource and the document path, so it is deleted the same way as when the endpoint is moved to another resource. After the exclusion is undone, the endpoint goes to "unassigned" or "no version", not to its previous resource, and the previous edit has nothing to apply to.
