The grouping of a resource is locked for editing only while its generation is waiting to start or running on at least one target; after generation ends, successfully or not, editing is allowed again, because a generation task must not read a grouping that is being changed at that moment. After generation ends, the user fixes the resource directly in the editor, without a workaround through a new resource. Under ADR-0068 such an edit removes the confirmation, and the resource has to be confirmed again.
