ScanJobWatcher is removed, and the panel learns about scans starting and finishing only through the new refresh mechanism, because per ADR-0076 the displayed data is refetched from the server on its own, so the result of any scan, whoever started it, already arrives this way. A separate job poll would be a second detector of the same event, and the project rule "one mechanism per behavior" forbids that. This way refreshing does not depend on the open page, since per ADR-0078 the other pages load fresh data when opened, and it adds no requests beyond ADR-0076, within the load limit per ADR-0084.
