A manual exclusion is not linked to exclusion by configuration: the scanner still parses the document, and the panel hides it when reading the active snapshot, does not count it in the active snapshot data, and shows it in the Scan document list marked "Excluded"; endpoints of non-excluded documents of the active snapshot go into the preliminary layout regardless of their status, because the document stays parsed in the snapshot, so the exclusion takes effect at once, as ADR-0148 requires, and the mark on the document under ADR-0155 makes it possible to show it in the Scan list under ADR-0152. The global excluded_segments setting does not change, and there is no need to pass per-service settings to the scanner: scan_repository currently accepts only repo and branch.

Supersedes: ADR-0041, ADR-0058.
