Field types are shown and chosen as Python SDK type annotations, for example str, int, datetime, list[InvoiceItem], because the user checks and fixes exactly the type the field will get in the SDK code. Under ADR-0107, the specification is built only for the Python SDK, so a separate panel notation and a translation from it into Python types are not needed.
