While no resource of the grouping is confirmed, the service card shows the summary "N resources in M versions, confirmation needed" and a button that opens the grouping editor, instead of the resource table, because the user stays on the service card and sees in one message the size of the result and the next step: checking the resources in the grouping editor (ADR-0063). The confirmation requirement is also not repeated in every row. The condition "no resource is confirmed" is unambiguous, because each resource is confirmed separately (ADR-0066).
