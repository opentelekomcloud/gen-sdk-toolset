The user confirms each resource separately, because a checked resource can go to generation right away while the others are still being edited: in the Python SDK each resource is a separate package services/<service>/<version>/<resource>/. The confirmation condition (ADR-0067), the removal of confirmation on edit (ADR-0068) and the ban on editing during generation (ADR-0069) are also defined per resource.
