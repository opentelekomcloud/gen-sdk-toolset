For each problem field the panel stores the currently selected type and the last action on it: selection, change or clearing the selection, with author and time, because the record of the last action covers all type actions from ADR-0104, including clearing the selection. So you can see who set the current type or cleared it, and when. A full history of earlier selections is not needed to check and fix types before generation.
