Each data query shown on screen is periodically refetched from the server on its own, with no changes on the backend, because the displayed data is read from the server again, so the panel will see any change, whoever made it. This also covers writes by CLI register-service and discover, which write directly to the DB, bypassing the HTTP API, as ADR-0079 requires. It also avoids introducing a shared revision number that would have to be incremented at every write point, and avoids holding long-lived connections through an external ingress whose configuration is not in the repository.
