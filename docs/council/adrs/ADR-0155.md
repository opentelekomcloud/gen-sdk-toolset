A manual document exclusion is stored in the snapshot as a mark on the document of this snapshot, because the Scan document list, the layout and the specification already read the documents of the active snapshot. So the mark on the document can be taken into account in the same queries: the exclusion takes effect at once under ADR-0148 and is hidden when reading under ADR-0154, and no separate storage outside snapshots is needed. For the exclusion to apply in later snapshots too, as ADR-0149 requires, the marks are carried over to the new snapshot by the document path (ADR-0150).
