Clicking a service in the /generation list opens the service generation page /generation/{encodeURIComponent(repo)}, where repo is the full service identifier from Scan; a list row shows only the service name, because the grouping is started, edited and confirmed from the service generation page, so the list must take the user there; the page opens under the conditions from ADR-0054. The address uses the full repo and follows ADR-0046, so the link can be matched with Scan data without a separate mapping table.

Supersedes: ADR-0045, ADR-0047.
