Operation building takes an endpoint's resource and version from the layout, not from the URI or the Scan document, including for endpoints that the user moved or assigned a version to manually, because under ADR-0064 and ADR-0059 the user moves endpoints between resources and assigns a version to endpoints for which the scanner did not find one. So the URI and the version from the Scan document cannot tell which resource and version an endpoint is in. Under ADR-0074, the layout gives the same resource and version as the services/<service>/<version>/<resource>/ package, and the specification shows exactly the operations that will go into it.
