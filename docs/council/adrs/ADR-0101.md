The type options for a problem field are the distinct recognized types of this field in the Scan documents of the active snapshot from which the class is built, because under ADR-0100 a field problem is a type mismatch between Scan documents, so choosing from the types recognized in these documents solves it directly and does not add options that are not in the documentation. Each option is linked to the document where it is given, and for a nested field ADR-0102 provides a link to the source table.
