Each edit is saved on the server immediately: the kind when a value is selected, the SDK method name on Enter or when the field loses focus, because the server recalculates the specification on every request (ADR-0115), so the user sees the resulting method right after the edit, without a separate button and without a long unsaved draft that would make the background refresh show "Data changed" (ADR-0083). Saving the kind and name separately does not create an invalid combination: under ADR-0122 the kind does not restrict the name. Concurrent edits by different users are stopped by the check under ADR-0134.
