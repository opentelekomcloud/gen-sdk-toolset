The user can delete an empty resource; in addition, they can rename a resource, move an endpoint to another resource of the same version, from the “unassigned” list to a resource of the same version or from the “no version” list to a resource of any version, and add a new resource; endpoints cannot be moved between versions, and the user sets a version only for endpoints whose version the scanner did not detect, because resources that became empty after endpoints were moved or after a rescan (ADR-0083) no longer pile up in the editor: the user removes them. At the same time, a resource the user plans to fill again does not disappear without their knowledge along with its id and name.

Supersedes: ADR-0064.
