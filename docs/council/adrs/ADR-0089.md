The saved layout determines which Scan endpoints belong to a resource and API version (ADR-0090), including manual moves and version assignments (ADR-0064, ADR-0059) and layout updates after a rescan (ADR-0083). Each endpoint contributes a source operation identified by its document path. The HTTP method and URI determine its kind. When the path ends in `/action` (ignoring the query string and a trailing slash), each distinct action identified in the documented request contributes a separate non-standard operation, because several actions can share the same HTTP method and URI. If the scan cannot identify an action, the source remains in the resource with a naming conflict.
