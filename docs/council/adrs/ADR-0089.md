The list of resource operations is built from the HTTP method and URI of the Scan documents that are bound to the resource in the current layout; the document's parameters, body and response are not used for this, because the contents of the resource are taken from the saved layout, as ADR-0090 requires. So the list of operations takes into account manual endpoint moves and assigned versions (ADR-0064, ADR-0059), as well as the layout update after a rescan (ADR-0083). Every Scan document has an HTTP method and a URI, so the set of operations does not depend on parsing the parameter, body and response tables.
