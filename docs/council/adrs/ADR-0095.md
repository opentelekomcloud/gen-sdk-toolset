The resource specification includes all classes that Python SDK generation creates for the resource: response models, their nested classes and the options class of each operation (*Opts) for the request body and query parameters, because this way the user sees all classes that will appear in the resource package and can fix problematic types of request body and query parameter fields, not only of the response. In the target SDK, operations have their own options classes, for example CreateVpcOpts and ListVpcsOpts next to the Vpc and Route models. This set matches the class roles from ADR-0094 and the ADR-0114 requirement that generation creates exactly the classes shown.
