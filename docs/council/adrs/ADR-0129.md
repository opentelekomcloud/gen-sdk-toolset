A merged SDK method calls one HTTP method and URI shared by all merged operations, because ADR-0128 and ADR-0118 merge into one method only operations with the same HTTP method and URI, so such a method always has a shared endpoint, and no route needs to be chosen at call time. The generation model under ADR-0114 stays unambiguous.

Supersedes: ADR-0093.
