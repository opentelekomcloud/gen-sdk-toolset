A type fix changes a field of one resource class in all operations of this resource that use this class, because a problem by ADR-0100 is a type conflict of a class field, and a class is built by ADR-0096 and shown in Entities together with the operations that use it by ADR-0094. So one fix removes the conflict where the user sees it, in all requests and responses of the resource. It does not touch fields of other classes. It does not touch other resources either: by ADR-0066 they are confirmed and generated separately.
