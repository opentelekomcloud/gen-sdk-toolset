The panel backend computes the preliminary grouping from the endpoints of the service's active snapshot, because the method, URI and API version of the active snapshot endpoints are already stored on the server in DocumentRecord. So the backend applies the ADR-0057 rule to them, does not send all endpoints to the browser, and writes the result directly to the storage from ADR-0074. Also, on the server the start can be protected by the worker role check under ADR-0070 and by the ban on starting again under ADR-0072, instead of relying only on hiding buttons in the client.
