A service excluded from Scan is not shown in the Generation list, even if it has a matching active snapshot; after the exclusion is undone, it is checked against the general selection conditions again, because Generation is built on the same set of services as Scan, so the user will not see in Generation a service they removed from Scan. No separate rule for excluded services and no separate unfiltered query are needed.
