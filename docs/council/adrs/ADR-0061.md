If the preliminary grouping fails, the service page shows the message "Failed to group endpoints" and a "Retry" button instead of the resource table, because the error appears in the same place where the user starts grouping and waits for the result under ADR-0056, so it cannot be confused with a service that has no resources. The user can retry right there, without going to another page, and ADR-0072 allows this, because after a failure the service still has no grouping.
