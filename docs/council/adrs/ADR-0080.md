While a tab is hidden, it does not request data; when the tab becomes visible again, it immediately refetches the data of the current page, the Header and the Attention Band, because nobody sees a hidden tab, so its background requests would create load in proportion to the number of open tabs rather than viewers, and would waste the ADR-0084 budget. Refetching on return shows the current state at the moment the user looks at the panel again, and adds a single rule to the periodic polling from ADR-0076, with no thresholds and no second mode.
