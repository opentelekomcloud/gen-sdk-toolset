The kind sets the generation template: a base method is built from the base operation template chosen by the endpoint's HTTP method and URI shape, and a custom method is built from the generic template of a direct endpoint call, because a manual kind change really changes the generated method: a base method gets the form of the python-t-cloud CRUD functions, for example an iterator through marker_paginate for list. The template is taken from the HTTP method and URI, like the operation list under ADR-0089 and the default name under ADR-0093, so it does not depend on the manual name, which under ADR-0122 the kind does not restrict.
