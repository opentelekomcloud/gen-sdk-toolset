A manual edit of the operation kind or SDK method name, like a field type fix, does not remove the resource confirmation, because the confirmation applies to the resource name and its set of endpoints. An edit of the operation kind and name, like a type fix, changes neither. Under ADR-0087 the specification opens only for a confirmed resource, so removing the confirmation would close the page after every edit. Generating a model the user has not seen is already ruled out by the check at start under ADR-0114.

Supersedes: ADR-0110.
