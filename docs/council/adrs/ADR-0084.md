Panel auto-refresh may add no more than 10% of backend and DB CPU time compared to running without auto-refresh under the same user load, because the periodic refetch per ADR-0076 is served by a backend that runs as a single replica. Summary and attention recompute the state of all services on every request, and the Header and the Attention Band refresh on all pages per ADR-0078. So a measurable limit is needed: it is used to check whether polling with the delay from ADR-0077 can handle the load from several users and tabs.
