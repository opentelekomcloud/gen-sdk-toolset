If the resources are not grouped yet, a single "Generate layout" button is placed in the center instead of the resource table; it starts the preliminary grouping of endpoints by their URI, because while there is no grouping, starting it is the only meaningful action on the service page. An explicit button lets the user choose when the grouping is created.

Supersedes: ADR-0047.
