When an endpoint is moved to another resource, the manual kind and name of its operation are deleted, and in the new resource the operation gets the default values, because under ADR-0126 an edit belongs to the resource and the document path, and the manual name is chosen with the neighboring operations of that resource in mind. So in the new resource the old name may be out of place or accidentally match the name of another operation. Resetting to the default values is a simple and predictable rule: there is no need to separately check whether the edit fits the new resource.
