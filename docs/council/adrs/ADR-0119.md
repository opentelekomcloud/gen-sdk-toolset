The default operation kind (base — get, list, create, update or delete — or custom) is set by a rule that is defined before implementation based on data from all services: it gives each operation exactly one kind and covers all HTTP methods and all URI shapes, including /resource/{id}/word. A manual edit replaces the rule's result only for an individual operation, because the URI shape alone cannot reliably tell CRUD apart from POST actions, searches and subresource operations in advance, so the rule is checked on real endpoints. A manual edit fixes the remaining classification errors on individual operations, and the user does not need to label the whole resource manually. The kind label under ADR-0091 and the method names under ADR-0093 and ADR-0120 still rely on each operation having one kind.

Supersedes: ADR-0092.
