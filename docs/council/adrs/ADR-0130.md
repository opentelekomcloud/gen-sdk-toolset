The resource specification includes all classes that Python SDK generation creates for the resource: response models, their nested classes, and the options class (*Opts) of each operation for the request body and query parameters. Each merged operation keeps its own options class (*Opts), and the SDK method accepts an instance of any of them, because the options class of each merged operation exactly repeats the fields, types and required flags of its document. Under ADR-0129 the method calls one shared endpoint, so the class passed determines only the request body and query parameters. The class roles under ADR-0094 stay the same, and no field-merging rule is needed.

Supersedes: ADR-0095.
