The user can undo a document exclusion, and after that the document takes part in the scan again, because the user can bring back a document excluded by mistake, and the exclusion already applies only until it is undone (ADR-0149). This way a document exclusion behaves the same as a service exclusion, which can also be undone under ADR-0043.
