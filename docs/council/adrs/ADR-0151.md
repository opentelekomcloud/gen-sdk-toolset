The user can cancel a document exclusion, and after that the document takes part in the scan again, because without cancellation the user cannot fix a mistaken exclusion on their own: exclusion by configuration of the scanner is set for all services at once and is not available to the user. This way document exclusion behaves the same as service exclusion under ADR-0043. The consequences of cancellation for the layout and operation edits are already defined in ADR-0158 and ADR-0159, and ADR-0149 keeps the exclusion until the user cancels it.
