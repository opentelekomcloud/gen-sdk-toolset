For a service that already has a layout, the user can run the preliminary layout again; before that, the panel asks for confirmation that all resources will be reset, because without a rerun, a service already laid out by the old rule, like api-gateway, would keep almost all its endpoints in one resource; with a rerun, it gets a layout by the rule of ADR-0135. The user starts the recalculation for the selected service, so the good layouts of other services do not change. Edits that must be kept are carried over by ADR-0140, and the confirmation before the reset protects against losing work by accident.

Supersedes: ADR-0072.
