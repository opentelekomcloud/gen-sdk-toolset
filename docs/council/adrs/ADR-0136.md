For a service that already has a layout, the user can run the preliminary layout again; before that, the panel asks the user to confirm that all resources will be reset. Otherwise, the layout is changed by edits in the editor, because a service with an established layout, such as api-gateway, moves to the ADR-0160 rule when the user decides, and the layouts of other services do not change. This needs neither a separate layout draft nor a re-layout of a single resource. The confirmation prevents an accidental reset of manual work, and ADR-0140 defines what is carried over to the new resources.

Supersedes: ADR-0072.
