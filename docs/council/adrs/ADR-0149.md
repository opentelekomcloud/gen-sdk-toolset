Document exclusion applies in all subsequent snapshots of the service until the user cancels it, because the user does not need to exclude the document again after each rescan, and the endpoint linked to the document does not come back into the layout on every scan. This is possible because under ADR-0162 the exclusion is stored outside snapshots, and under ADR-0150 the document is recognized by its file path. Service exclusion from Scan already works the same way: it applies until it is lifted via /include.
