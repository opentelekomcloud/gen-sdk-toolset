A document exclusion applies in all later snapshots of the service until the user undoes it, because the user does not need to exclude the document again after each rescan, and the document does not return to the scan without the user's decision. Otherwise, under ADR-0158 and ADR-0159, the document's endpoint would go to "unassigned" or "no version", and its operation would be reset to the default kind and name. Recognizing the document by its path (ADR-0150) and undoing the exclusion (ADR-0151) make such a lasting exclusion predictable and reversible.
