The row of an operation with a manual edit has a "Reset" button that deletes the manual kind and SDK method name in one action, after which the operation gets the default values again, because one action returns the operation to the automatic values, and the user does not need to know or enter the default values. After a reset the operation again follows the rules of ADR-0119 and ADR-0120, including when these values change after a rescan.
