When a document is excluded, the binding of its endpoint to a resource is deleted; when the exclusion is undone, the endpoint goes to "unassigned" if it has an API version, or to "no version" if it has none. On a rescan, the saved layout keeps the remaining endpoints in their resources and deletes the ones that disappeared; new endpoints go to "unassigned" if they have an API version, or to "no version" if they have none, and from there the user moves them into resources. While the page has unsaved edits, the panel does not change the data being edited but shows the message "Data changed" with a "Refresh" button; the button discards the edits and loads the current state, because the layout reacts the same way to any change of the set of endpoints: excluding and undoing the exclusion work the same as an endpoint disappearing and appearing on a rescan. Under ADR-0156 endpoints of excluded documents do not get into the layout, so after their exclusion a resource has no hidden bindings left, and deleting a resource that is empty under ADR-0145 loses nothing of them.
