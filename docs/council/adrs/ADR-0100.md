A class field is a problem field if different Scan documents give it different types after normalization, because when structures from several documents are merged into one class under ADR-0096, the field must keep one type, and the generator cannot choose between contradicting documents by itself. Since Scan already normalizes how types are written, different spellings of one type do not count as a problem, and the distinct recognized types from the documents serve as choice options under ADR-0101.
