Only the Header, the Attention Band and the open page refresh on their own, without navigating to a page, and the other pages load fresh data when opened, because the Header and the Attention Band are visible on every page, so the user notices other people's changes wherever they are, and the page they open does not show a stale cache because it loads the data again. Data the user does not see is not fetched in the background, which makes it easier to stay within the load limit from ADR-0084: summary and attention recompute the state of all services on every request.
