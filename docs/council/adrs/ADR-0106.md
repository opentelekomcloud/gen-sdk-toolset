Resource generation cannot be started while the resource has at least one problem field without a chosen type, because a field that Scan documents give different types (ADR-0100) gets into the SDK only with the type the user chose, not with a generic type that hides the conflict. Only this resource is delayed, because resources are confirmed and go to generation separately (ADR-0066).
