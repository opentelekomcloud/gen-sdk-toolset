The user can rename a resource; move an endpoint to another resource of the same version, from the "unassigned" list to a resource of the same version, or from the "no version" list to a resource of any version; and add a new resource. Endpoints cannot be moved between versions, because in the target Python SDK a resource is a package inside a version (services/<service>/<version>/<resource>), so an endpoint must not leave its version. The user sets a version only for endpoints whose version the scanner did not determine, as ADR-0059 provides. Endpoints in the "unassigned" list already have a version under ADR-0057.
