A resource can be confirmed only if all its endpoints have status OK, because under ADR-0058 endpoints with any status go into the grouping, and without this check a user could confirm a resource with endpoints that are not ready for generation yet. Under ADR-0066 each resource is confirmed separately, so an endpoint that is not in status OK blocks confirmation only of its own resource, not of the whole grouping.
