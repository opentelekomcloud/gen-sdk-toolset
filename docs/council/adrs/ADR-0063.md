edit layout leads to the page /generation/{encodeURIComponent(repo)}/layout, where repo is the full service identifier from Scan, because a separate page gives the editor room to work with many endpoints and with the moves allowed by ADR-0064, and it can be opened by a direct link. The frontend already has the route /generation/:name/layout with the GenerationLayoutPage editor and an "edit layout" link that leads to it.
