An excluded document is recognized by its file path in the service repository, because the document path is the same in all snapshots of the service, while the id of a DocumentRecord row is created anew in each snapshot. So by the path, the exclusion mark from ADR-0155 can be carried over to later snapshots, as ADR-0149 requires. The path tells apart documents with the same HTTP method and URI. The binding of an endpoint to a resource in the layout and the operation edits under ADR-0126 are stored by the same key.
