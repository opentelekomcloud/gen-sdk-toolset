An excluded document is recognized by its file path in the service repository, because the document path is the same in all snapshots, while DocumentRecord rows are created anew in each snapshot. So the path lets the exclusion carry over to all subsequent snapshots, as ADR-0149 requires. The path distinguishes documents with the same HTTP method and URI. The binding of an endpoint to a resource in the layout and the operation edit under ADR-0126 are already tied to this same path. The cost of this choice: if the file is renamed or moved, the exclusion stops working.
