Operations are merged into one SDK method only if they have the same resource and version, the same HTTP method and URI, and the same kind and method name; the rule that tells apart operations with the same default method name, including those with different URIs, is defined before implementation based on data from all services, because under ADR-0089 the operation list is built from Scan documents, so the same endpoint can come from several documents, and it is exactly such duplicates that must be merged. With the same HTTP method and URI, the merged method calls exactly one endpoint, as ADR-0129 requires, and different API calls are not hidden behind one name. The same kind leaves the merged operations with one generation template under ADR-0123.

Supersedes: ADR-0093.
