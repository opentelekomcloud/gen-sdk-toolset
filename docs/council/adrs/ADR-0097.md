The rule for SDK class and field names is defined before implementation using data from all services. It must give valid Python names, the same names on every generation and different names for different classes and fields of one resource. The original field name stays the JSON key, because the rule is chosen from the real name forms in all services, so a rule fitted to one service will not produce invalid or clashing names in the others. The original field name stays the JSON key, so API requests do not change, and this name can be shown next to the SDK field name, as ADR-0094 requires.
