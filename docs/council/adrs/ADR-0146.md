The layout response returns, for each endpoint, a source_url link to the document on GitHub at the commit of the active snapshot, because ADR-0144 opens an endpoint's document by a link to GitHub at the commit of the active snapshot, so a ready link in the layout response opens it right away, without a second request. The specification already links to an operation's document through the same source_url (ADR-0091), and both pages lead to a document the same way.
