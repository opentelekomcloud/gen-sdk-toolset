A manual operation edit stays in effect after a rescan as long as the operation's default kind and name stay the same; if they change, the edit is deleted and the operation gets the new default values, because the user's work is kept on operations whose default kind and name the rescan did not change, and an edit made under other default values does not carry over to new data without the user's decision. Type fixes behave the same way under ADR-0109, so edits on the specification page follow one approach.
