If a background refresh fails, the panel replaces the block that failed to refresh with an error message and a "Retry" button, as when the first load fails; a block with unsaved edits is not replaced but shows a refresh error warning next to the data; if the list of services cannot be fetched, the /generation page, including on the first load, shows an error message and a "Retry" button instead of the table, because an explicit error message prevents mistaking unconfirmed data or a backend failure for the current state, and the behavior on error is the same for the first load and for a background refresh. A block with unsaved edits stays in place so that a refresh failure does not erase the user's work, just like someone else's change per ADR-0083.

Supersedes: ADR-0051.
