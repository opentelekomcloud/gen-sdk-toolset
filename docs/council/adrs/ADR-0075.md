The frontend takes the grouping data types from schema.gen.ts, which is generated from the backend's OpenAPI schema, because the backend computes and stores the grouping (ADR-0073, ADR-0074), so types generated from its schema catch mismatches between client and server at build time, while hand-written types can silently drift from the real API responses. Also, the frontend project rule "Types come from the backend" requires taking types from schema.gen.ts.
