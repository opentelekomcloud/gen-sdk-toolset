A request to edit a field passes the value the user saw: the selected type or no selection; a request to edit an operation passes the kind and method name the user saw. If the server already has other values stored for the field or the operation, the server rejects the request, and the panel shows "Data changed" with a "Refresh" button, because an open page can lag behind the server by up to 15 seconds (ADR-0077), and without the check the user would silently overwrite someone else's deliberate choice of type, kind or name. Checking the kind and name together prevents a combination that nobody chose, and merging operations under ADR-0128 depends on both values matching. The current values are enough for the check, so neither a shared revision nor a lock that would have to be released is needed.

Supersedes: ADR-0113.
