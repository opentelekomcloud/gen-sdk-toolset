Endpoints of one version that get the same resource name under the new rule go into one resource, because the layout does not invent new names: the resource name stays a URI segment that the user understands, and one resource per name directly keeps names unique within a version, as ADR-0074 requires. If such a resource gets endpoints from different parts of the API, the user splits it manually in the layout editor.
