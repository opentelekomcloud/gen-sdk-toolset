Endpoints without an API version are not part of any resource. They are shown in a separate "no version" list, from where the user moves them into resources of the right version, because the version of an endpoint is set by the user, not by an automatic rule, when the scanner did not find it. So the Python SDK, where a resource is the package services/<service>/<version>/<resource>/, gets no artificial version segment, and the endpoints themselves stay visible. ADR-0064 already allows moving endpoints from the "no version" list into a resource of any version.
