If endpoints with a different part of the URI before the name segment get the same resource name, the previous static segments of the URI are added to the names of these resources with "_", one at a time, until the names in the version are distinct, for example backups and instances_backups. A resource whose segment has no previous static segment keeps its name without an addition. If the names are still the same after all previous static segments are added, the endpoints of these resources go to the "unassigned" list of their version. The resource name is converted to lower case, invalid characters are replaced with "_", and the prefix "r_" is added to a name that does not start with a letter. Endpoints without a static segment after the version go to the "unassigned" list of their version, because resources from different parts of the API, split under ADR-0160, do not merge back into one large resource under a common name. Names stay meaningful and get longer only where they cannot be told apart otherwise, and if they cannot be told apart by the URI, the layout does not invent a name and leaves the endpoints to the user.

Supersedes: ADR-0057.
