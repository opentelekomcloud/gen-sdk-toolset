While grouping is running, we show a spinner, because under ADR-0073 the panel backend computes the grouping, so after the user clicks "Generate layout" from ADR-0056 the result does not arrive at once and the user needs simple feedback. A spinner gives this feedback without a separate layout for the waiting time, and the panel already shows loading this way (Loader2 with animate-spin).
