On the Scan page the user can manually exclude a document from the scan, because under ADR-0152 excluded documents are already visible in the service document list in Scan marked "Excluded", so the exclusion and undoing it under ADR-0151 are in one place. The rows of this list already contain the document path, by which the exclusion is recognized under ADR-0150, and the action itself does not depend on whether the service got into the Generation list.
