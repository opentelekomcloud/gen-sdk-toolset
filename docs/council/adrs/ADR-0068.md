Editing a resource after it is confirmed removes the confirmation only from that resource; moving an endpoint removes it from both affected resources, because resources are confirmed separately (ADR-0066), so a confirmation must apply to exactly the name and set of endpoints that the user checked, and unchanged resources keep their confirmation. The name also needs a new check: in the Python SDK a resource is a separate package, and its name becomes the package name.
