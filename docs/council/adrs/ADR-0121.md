A manual SDK method name must match the pattern ^[a-z][a-z0-9_]*$ and must not be a Python keyword or the name of an internal module of the resource package (common, __init__), because in python-t-cloud a resource method is a function in a module of the same name in the package, next to common.py and __init__.py, so the name must work both for a function and for a module. The pattern matches the lowercase style of the SDK and the rule the server already uses to check the resource name. At the same time, a meaningful name that is not in the URI can be set, for example search.

Supersedes: ADR-0093.
