The resource specification page has two sections: Operations and Entities, because before generation the user checks the operations and classes of the resource. Under ADR-0099, type problems are already shown in the field rows of the Entities section, so a separate section for them is not needed. A shared class is shown in Entities once, not under each operation, and this matches ADR-0108: a type fix changes the class in all operations of the resource.
