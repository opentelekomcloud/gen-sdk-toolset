Within a resource, structures with the same non-empty type_name from Scan are merged into one class, because type_name is already stored in IR Parameter, so the rule needs no scanner changes and brings one structure from different operations into one model, even if its fields differ between documents. Type mismatches become field problems by ADR-0100 and are fixed once for the whole class by ADR-0108.
