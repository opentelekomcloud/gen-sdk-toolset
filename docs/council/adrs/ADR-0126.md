An operation edit is bound to the resource and the path of the endpoint's source document, because the edit is stored by document path, the same way as the binding of an endpoint to a resource in the layout. So it does not depend on document rows, which are created anew in each snapshot, and it tells apart documents with the same HTTP method and URI. Binding to the resource keeps the edit within the bounds where operations are merged under ADR-0128, and is consistent with ADR-0127: when an endpoint is moved to another resource, the edit is deleted. If the path is the same but the default kind or name changed, the edit is deleted under ADR-0117.
