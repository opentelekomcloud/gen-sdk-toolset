after we confirm a resource, the service page shows a list of resources available for generation; each has a Generate button, and clicking it opens the generation spec. The service page and the layout page open for any service from the /generation list, that is, for a service with endpoints in the active snapshot. If there is no layout yet, the layout page shows an empty state with a link to the service page. For any other repo both pages show PageNotFound, and the result page shows PageNotFound for any service. If someone else's change makes the shown object unavailable, the open page shows the same screen as when opened by direct URL. If the page has unsaved edits, this screen is shown only after clicking “Refresh” in the “Data changed” message, because Generate opens the specification instead of starting generation right away. So before the start, the user sees the operations, classes and problem fields of the resource. Only confirmed resources have the button, that is, the resources for which ADR-0087 opens the specification.
