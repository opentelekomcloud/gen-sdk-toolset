If a resource name from a URI segment matches a Python keyword, the layout does not create a resource for these endpoints and puts them in the “unassigned” list of their version, because the layout does not invent a replacement for an invalid name. ADR-0057 does the same with endpoints whose resource cannot be determined from the URL: they go into the existing “unassigned” list, and the user chooses a meaningful resource name and moves them there. This way, a keyword name never appears in the layout.
