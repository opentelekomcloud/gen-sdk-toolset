If a resource name from a URI segment matches a Python keyword, the layout does not create a resource for these endpoints and puts them in the "unassigned" list of their version, because the layout does not replace an invalid name with an invented one. These endpoints, like the endpoints whose resource cannot be determined from the URL under ADR-0057, stay visible in the "unassigned" list, and the user chooses their resource name. A separate rule for mangling the resource name is not needed.
