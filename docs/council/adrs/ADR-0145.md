A resource counts as empty if it has no endpoints from the active snapshot, even if resource_endpoint still has references to paths that are not in this snapshot, because the layout editor shows only endpoints of the active snapshot, and references in `resource_endpoint` to paths outside it are not visible. So a resource counts as empty when the user sees it as empty and can delete it under ADR-0142, including a resource that all endpoints left after a rescan under ADR-0083. We accept the cost of this choice: when such a resource is deleted, its hidden references are deleted with it. Endpoints that come back when the snapshot changes will go to “unassigned” or “no version”.
