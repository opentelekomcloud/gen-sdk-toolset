The preliminary grouping includes all endpoints of the service from the active Scan snapshot, regardless of their status, except endpoints of excluded documents: endpoints of excluded documents do not get into the Generation layout, they are neither in the preliminary grouping nor in the layout editor, because under ADR-0148 and ADR-0154 an excluded document is already not counted in the data of the active snapshot. So the operation list (ADR-0089), the field type options (ADR-0101) and the resource confirmation check (ADR-0067) need no separate rules for excluded documents. The user sees excluded documents in the Scan document list with the "Excluded" mark under ADR-0152, so a separate list in the layout editor is not needed.

Supersedes: ADR-0058.
