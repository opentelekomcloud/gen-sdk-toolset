Endpoints of excluded documents do not get into the Generation layout: they are neither in the preliminary grouping nor in the layout editor; the other endpoints of the service from the active snapshot go into the preliminary grouping with any status, because the user excludes a document so that it no longer takes part in the work. Under ADR-0154 the panel already does not count such a document in the active snapshot data, so its endpoint drops out of resources, the operation list and the problem fields without separate rules. The user sees the excluded documents themselves in the Scan list marked "Excluded" under ADR-0152.

Supersedes: ADR-0058.
