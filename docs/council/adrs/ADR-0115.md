The panel backend computes the operations, classes and field problems on every specification request, and the frontend shows the ready response, because the resource layout is stored on the server (ADR-0074), and field parameters and document links are currently returned only by the server's detailed read of an active snapshot document. So the server assembles the specification in one request, without loading all resource documents into the browser, and builds the model for generation under ADR-0114 with the same function. Computing on read immediately takes into account rescans, layout edits and writes through the CLI, and it does not need to be repeated at every write point, just like re-reading data in ADR-0076.
