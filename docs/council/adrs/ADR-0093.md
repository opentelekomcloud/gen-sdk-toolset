For ordinary operations, the HTTP method and constant URI segments determine the proposed Python method name. Basic operations on the resource use `create`, `get`, `list`, `update` or `delete`, matching the functions in the `services/vpc/v1/vpcs` package of python-t-cloud. Nested literals qualify the name, as in `list_routes`, because ADR-0057 groups subcollections under the same resource. An ordinary non-standard operation uses the nested literals joined with underscores, or the resource literal for a root operation.

For a terminal `/action`, use the request discriminator from ADR-0089. A named body key gives `add_security_group` for `addSecurityGroup` and `start` for `os-start`. A documented action value in the body or query includes the affected collection, as in `create_tags`. A nested key includes its object context, as in `associate_subnets` for `routetable.subnets.associate`.

Normalize proposed names to Python identifiers in snake_case and check them across the whole layout resource. If a selector is missing or ambiguous, or a name cannot be formed or still collides, keep each source operation and record a machine-readable reason for review. A collision retains the proposed spelling on each affected operation. This keeps names reproducible for the generation model (ADR-0114) across document reordering, page-title edits and resource renames.
