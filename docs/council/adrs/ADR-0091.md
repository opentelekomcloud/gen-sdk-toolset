For each operation I see whether it is basic or non-standard, what its SDK method will be called and which endpoint it comes from, with a link to the document, because the kind label shows at once how the rule of ADR-0092 classified the operation, so a classification error is visible directly, not only through the method name. The method name from ADR-0093 and the endpoint with a link to the document let me check before generation which method will be created and where it comes from.
