A type fix stays in effect as long as, after a change of the documents or the layout, the field has the same problem and the selected type is among its options; otherwise the fix is removed; if the field still has a problem, it is considered unresolved again, because the user's work is not lost on fields that the change did not affect. In the same way, by ADR-0083 the saved layout keeps what remains after a rescan. A stale selection does not silently get into generation: if the problem has changed or the selected type is no longer among the options by ADR-0101, the field again needs a decision. A field that is no longer a problem field by ADR-0100 does not block starting generation by ADR-0106.
