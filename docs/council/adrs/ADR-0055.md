The service generation page offers two targets: Python SDK, selected by default, and Ansible modules, with a note that generation for it is not connected yet, because under ADR-0074 a grouping resource is stored without a link to a target, so a second target does not change what the user groups, edits and confirms. The note on Ansible modules shows clearly that generation for it is not connected yet, and the second target and the choice between targets will not have to be added again later.

Supersedes: ADR-0047.
