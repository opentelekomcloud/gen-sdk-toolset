A field type fix does not remove the resource confirmation, because under ADR-0068 the confirmation applies to the resource name and the set of its endpoints, and a type fix changes neither. Under ADR-0087, the specification opens only for a confirmed resource, so removing the confirmation would close it after every fix, and ADR-0106 already checks that the types are ready for starting generation.
