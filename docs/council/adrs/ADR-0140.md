On a repeated layout, all resources are laid out again, and edits of operation kinds and names and selected field types are carried over to the new resource of the same version with the same name if their endpoint went to this resource; other such edits are deleted, because the repeated layout applies the ADR-0160 rule to all endpoints. So a large resource like apigw is split even if it was renamed, had endpoints moved into it or was confirmed before. Work on the specification page is kept where the endpoint stayed in a resource of the same version with the same name. Edits of endpoints that went to another resource are deleted, as on a move under ADR-0126.

Supersedes: ADR-0072.
