On a repeated layout, all resources are laid out again. Edits of operation kinds and names and the selected field types move to the new resource of the same version with the same name if their endpoint went into that resource; other such edits are deleted, because the rule of ADR-0135 applies to all endpoints of the service, so earlier manual edits and confirmations do not prevent splitting a large resource such as apigw. Work on the specification page is kept where a resource of the same version kept its name: by ADR-0138, such a name gives exactly one resource in the version. An edit of an endpoint that moved to another resource is deleted, as in ADR-0126.

Supersedes: ADR-0072.
