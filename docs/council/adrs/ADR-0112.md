Only a user with the worker role can fix field types in the specification; a user with the viewer role sees the problems and chosen types read-only. Only a user with the worker role can also start, edit and confirm the layout; a user with the viewer role sees the layout read-only, because this way type fixing follows the role model that the panel already applies to the layout: changing routes require require_worker, and no new role in Zitadel is needed. In the idea, the same user who checks the specification before generation fixes the problematic types, so a separate approval step and tying the right to whoever confirmed the resource are not needed.

Supersedes: ADR-0070.
