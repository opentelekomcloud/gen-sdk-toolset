Operations of a resource with the same version, HTTP method, URI, kind and method name are merged into one method: this is how the user specifies which documents to combine. If operations that cannot be merged under these conditions have the same name, the Operations section marks them as a conflict, and resource generation does not start until the conflict is resolved, because the same name remains the way to combine documents of one call under ADR-0120 and ADR-0128, and any other match does not reach generation. In a python-t-cloud resource package, the method name is the same as the function and module name, so two different methods with one name are impossible there, and the model under ADR-0114 will not get such a pair. The conflict is visible in the specification, which the server builds on every request under ADR-0115, so the system catches a match from any source and does not replace a name set by the user.

Supersedes: ADR-0093.
