The resource specification is built only for the Python SDK target and does not open for the Ansible modules target until its generation is connected. The service page and the layout page open for any service in the /generation list, that is, for a service with endpoints in the active snapshot. If there is no layout yet, the layout page shows an empty state with a link to the service page. For any other repo both pages show PageNotFound, and the result page shows PageNotFound for any service. If someone else's change makes the shown object unavailable, the open page shows the same screen as when the direct URL is opened. If the page has unsaved edits, this screen is shown only after clicking "Refresh" in the "Data changed" message, because the operations, classes and field types of the specification are defined in terms of the Python SDK (ADR-0093, ADR-0095, ADR-0098), and Ansible modules generation by ADR-0055 is not connected, so there is nothing to build its specification from. By ADR-0074 a resource is stored without binding to a target, so connecting Ansible modules will not require changing the layout or the confirmation.

Supersedes: ADR-0082.
