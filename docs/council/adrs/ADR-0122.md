The operation kind does not restrict the name of its SDK method: both a base and a custom operation can be manually given any valid name; the default name is still built from the kind: a base operation gets create, get, list, update or delete, a custom operation gets the name of the last constant URI segment, and for a nested path the constant segments after the first are appended to the name with "_", because the user fixes the classification and the method name independently: changing the kind does not require renaming, and a needed name does not force a kind change. The generation template under ADR-0123 is set by the operation kind, and whether a manual name is allowed is checked under ADR-0121.

Supersedes: ADR-0093.
