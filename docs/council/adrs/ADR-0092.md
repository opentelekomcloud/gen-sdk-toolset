The rule by which an operation is considered basic (get, list, create, update, delete) or non-standard is defined before implementation using data from all services. It must give each operation exactly one kind and cover all HTTP methods and all address forms, including /resource/{id}/word, because the URI form alone cannot reliably tell CRUD apart from POST actions, search and subresource operations in advance, so the rule is checked on real endpoints. Each operation needs exactly one kind: method names by ADR-0093 and how the operation is shown in the specification by ADR-0091 rely on it.
