An operation is basic if its HTTP method and URI shape give one of the kinds: GET on a collection — list, GET on an item — get, POST on a collection — create, PUT or PATCH on an item — update, DELETE on an item — delete; the nesting depth of the path does not matter, and all other operations are non-standard.
