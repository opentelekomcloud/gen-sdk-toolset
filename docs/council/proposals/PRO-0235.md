A basic operation gets the name create, get, list, update or delete, and a non-standard one gets the name of its last constant URI segment; for an operation on a nested path, the constant URI segments after the first constant segment (after the version segment and path parameters) are added to the name with "_", for example list_routes or tags_action. Method names within one resource must be different: the rule that tells apart operations with the same name, including ones with different URIs, is defined before implementation using data from all services.
