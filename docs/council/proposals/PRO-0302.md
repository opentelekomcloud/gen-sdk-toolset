The default SDK method name is built by the ADR-0093 rule: a base operation gets the name create, get, list, update or delete, a custom operation gets the name of the last constant URI segment, and for a nested path the constant segments after the first are appended to the name with "_". All default names within one resource are distinct; the user can enter the same name to merge endpoints into one operation.
