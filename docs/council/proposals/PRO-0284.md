When generation starts, the server saves with the job the model of the resource's operations and classes, built by the same function as the specification, and the generator creates code only from this model; at start, the server rejects generation if the model has changed since the specification was shown (for example, by hash), and the page shows “Data changed” with a “Refresh” button
