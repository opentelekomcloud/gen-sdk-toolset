Endpoints of the same API version go into one resource if their URIs share the first constant segment after the version segment, if the URI has one, and after path parameters such as {project_id}. The resource name is this segment in lowercase, with invalid characters replaced by “_”; if it does not start with a letter, the prefix “r_” is added. Endpoints whose segments produce the same name go into one resource. Endpoints that have no constant segment after the version go into the “Unassigned” list, from which the user moves them into resources manually
