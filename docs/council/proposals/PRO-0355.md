If endpoints with a different part of the URI before the name segment get the same resource name, the previous static segments of the URI are added to the names of these resources with "_", one at a time, until the names in the version are distinct, for example backups and instances_backups. A resource whose segment has no previous static segment keeps its name without an addition. If the names are still the same after all previous static segments are added, the endpoints of these resources go to the "unassigned" list of their version.
