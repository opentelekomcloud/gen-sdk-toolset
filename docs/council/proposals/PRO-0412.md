Endpoints of one version are first grouped by the first static segment of the URI. A group that contains more than half of the version's endpoints is split by the next static segment. If all endpoints of the group that have a next static segment share the same one, the layout skips it and splits the group by the first segment where the endpoints differ. An endpoint whose static segments run out earlier stays in a resource named after its last static segment. Splitting repeats until no group exceeds the threshold or until the endpoints of a large group run out of static segments.
