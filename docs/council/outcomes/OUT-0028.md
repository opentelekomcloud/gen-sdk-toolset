A list loading error is shown clearly and the request can be retried

If the service list could not be loaded from the backend, the /generation page shows an error message and a "Retry" button instead of the table. This also applies to the first load. This page cannot be confused with an empty list of matching services. The "Retry" button requests the list again without a page reload. If the new request succeeds, the message disappears and the page shows the table.

Acceptance criteria:
- If the backend did not return the service list when /generation is first opened, the page has an error message and a "Retry" button, and has no table.
- The page shown on a list loading error is different from the page shown when the backend returned an empty list.
- Clicking "Retry" requests the list from the backend again without a page reload.
- If the list is loaded successfully after clicking "Retry", the error message disappears and the page shows the table with services.
