The caption above the list states the selection condition

The caption above the /generation list lists all selection conditions accepted in ADR-0041. There is one condition: the number of endpoints in the service's active Scan snapshot is greater than zero. The old description "scanned or partially scanned" is no longer shown. In every interface language, the caption describes the same condition.

Acceptance criteria:
- The caption above the /generation list says that the list includes services whose active Scan snapshot has more than zero endpoints.
- The caption speaks specifically about the active snapshot.
- The caption does not describe the selection as "scanned or partially scanned" and does not name Scan statuses as a selection condition.
- In each interface language, the caption describes the same selection condition.
