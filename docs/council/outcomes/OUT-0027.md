The /generation table shows only service names

When the list is loaded, the table on the /generation page shows only the name of each selected service. A row has no other information about the service, including information about generation, resource layout and PRs. The table has no generation target columns, and the page has no generation state chips either. Generation states are hidden for now: they will be shown again when real generation data is connected. The existing generation state types do not change.

Acceptance criteria:
- After a successful load, each row of the table on the /generation page shows the service name and no other data about the service.
- The /generation table has no generation target columns.
- The /generation page has no generation state chips.
- No row has information about generation, resource layout or PRs.
